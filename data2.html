CSS Qus & Ans

1. what is the difference between box- sizing: content-box and border-box?

with content-box , width and height apply only to then content, so padding and borders add to the element's total size.
With border -box, padding and borders are included inside the specified, width and height.

2. what are the main CSS position values?

static is the default normal document flow.
relative offsets the elements from its normal positions without affecting surrounding elements.
absolute positions the element relative to its nearest positioned ansector.

3. what is the CSS BOX MODEL?

Every HTML elements is treated as a rectangular box made of four concentric layers .
From the inside out, these layers are content , padding , border, and margin elements.
